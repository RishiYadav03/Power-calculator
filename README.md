# Power-calculator
📐 Square, Cube & Positive Number Calculator (HTML + Bootstrap + JavaScript)

This simple yet functional web calculator allows users to input a number and instantly calculate:

🔲 Square of the number (number × number)

🧊 Cube of the number (number × number × number)

✅ Whether the number is positive, negative, or zero

💡 Features:

Responsive Design: Built with Bootstrap, the layout adapts well to mobile, tablet, and desktop views.

Interactive UI: JavaScript handles all logic and dynamically updates the result without reloading the page.

User-Friendly: Clear input field, action buttons, and output display area.

Real-Time Feedback: Displays all results with a single click.

🛠️ Tech Stack:

HTML for structure

Bootstrap for styling and responsive layout

JavaScript for calculation logic and DOM manipulation
